# MS Studio — Weddings by Umair · Stage 2

A source-code website built with **Astro 4, React 18, TypeScript and Tailwind CSS**, designed for independent deployment via **GitHub → Netlify**. This is an enhanced continuation of the original Claude Stage 1 project, not a new project.

## What is included

- Editorial wedding homepage with a real photograph extracted from the studio's supplied 2025–26 brochure.
- Six brochure-derived photography examples in a filterable, expandable image gallery; original images can replace these.
- Three official PDF wedding packages, 23 add-on entries (including separate photobooth variants and album options), editorial package cards, and detailed FAQ/terms.
- **Multi-event calculator**: separate Nikkah, Mehndi, Baraat, Walima, or other functions, each with independent package, add-ons, quantity and date; combined price; bespoke base-quote warnings; WhatsApp sharing; print-to-PDF; Netlify quotation enquiry.
- Founder and team sections supporting future portraits via `src/assets/team`.
- WhatsApp, Instagram, Facebook, Google Maps/Business Profile, Behance and LinkedIn configuration.
- Contact page using Netlify Forms and location map.

## Set up locally (Node.js 22)

```bash
npm install
npm test
npm run build
npm run dev
```

Open the local dev URL printed by Astro. If the build fails, read the exact error and correct it before going live. Commit the real `package-lock.json` generated by npm to your GitHub repository. We have intentionally **not** included a fabricated lockfile.

## Deploy through GitHub + Netlify

1. Create a new **empty repository** named `msstudio-weddingsbyumair` in GitHub. Add the **contents of this folder** to the repository root, so `package.json` sits at the root (not inside a second `ms-studio` folder).
2. In Netlify: **Add new project/site → Import an existing project → GitHub**, authorize the repository and select the new repository.
3. Configure **Build command** `npm run build`, **Publish directory** `dist`, **Node** `22` (`netlify.toml` and `.nvmrc` already specify 22).
4. Select an available Netlify site name. The two suggested domains are not guaranteed to be available.
5. Update the new domain in both `astro.config.mjs`, `src/data/site.ts`, and `public/robots.txt`. Commit again to GitHub.
6. **Only when approvals, photo permissions, build and forms tests are complete:** change `site.launchApproved` from `false` to `true` in `src/data/site.ts` so Google is allowed to index the site.
7. In Netlify dashboard check Forms for `booking-enquiry` and `quote-enquiry`. Set up email notifications and submit real test enquiries. Confirm each entry arrives before relying on these forms.
8. Verify the actual site from your phone and laptop, check social links and review the complete booking terms.

**Credit reminder:** GitHub code generation avoids Netlify's AI Agent, but Netlify builds, bandwidth, forms and hosting can still count toward your team's credit allotment. Both business websites may share the team's credits.
